# 小A · 知识闯关教练（xiaoa-knowledge-coach）

把任意知识库变成可以玩的闯关游戏——自动出题、逐选项讲解、**AI 语音朗读（中英文自动切音色、语速分档）**、RAG 防幻觉答疑、遗忘曲线复习，一键生成单文件 H5，**默认发布永久公开的在线链接并据内容生成二维码海报**，PC 与手机双端自适应，**微信场景两段验收：二维码微信扫得出 + 链接微信打得开**。

## 类型

Agent 型（单个 AI 专家）· 行业分类：03-GameSpatial（游戏空间）

## 核心功能

1. **知识库转闯关 H5**：给一份知识文件（HTML / Markdown / 统一 Schema 的 JSON），生成单文件 `index.html`——关卡地图、答题判分、逐选项反馈、段位与 XP、星图复习、智能体对话面板一应俱全，纯静态无后端。
2. **AI 语音朗读**：内置系统 TTS（`assets/tts.js`），零依赖可离线。中英混排内容（如 `red红色，blue蓝色`）会**先按语言分段再逐段切音色**；题干、选项、解析都能单独点读。中文与英文语速分开设置，移动端自动解锁 + 看门狗兜底。
3. **出题与逐选项讲解**：不只要正确答案，还要每个选项的针对性反馈（错在哪、为什么）。干扰项优先取自同场景真实内容，不凭空编造。
4. **RAG 防幻觉答疑**：回答基于知识库原文检索，引用来源；库里没有的明确说不确定。
5. **学习诊断与复习规划**：基于答题画像生成诊断报告，按遗忘曲线安排复习队列，推荐下一步学习路径。
6. **双模架构**：不填 API Key 也能完整运行（离线预生成模式）；填入大模型接口后自动升级为实时生成式对话，超时自动回落，永不空白。
7. **在线链接 + 二维码海报（默认动作）**：成品出来就主动发布成**永久公开**的 `https://<id>.app.workbuddy.link`——托管在云端，**与本机开关机无关**（关机/退出程序/换电脑都不影响别人访问），并据本次成品内容生成二维码海报。离线单文件是双保险。
8. **PC / 手机双端自适应**：移动优先布局——手机（<600px）单列、平板（≥600px）双列、PC（≥900px）三列主网格 + 选择题双列 + 弹层居中，超宽屏再放宽；响应式全部内建在 `template.html`，引擎代码零改动。
9. **微信生态交付（重点）**：对外分享基本都在微信里，所以这是验收线，分两段：
   - **① 二维码微信扫得出**：静区 ≥4 模块（ISO/IEC 18004）、前景纯黑、模块整数倍 ≥4px、成品内 ≥300px，且必须过一遍**模拟微信压缩链路**（720px 宽 → JPEG q55 → 高斯模糊）仍能解出。另附 795px 独立二维码供视频/PPT/印刷使用。
   - **② 链接微信打得开**：内置 `wechat_check.py` 用真微信 UA 复测。⚠️ **已实测：默认宿主 `*.app.workbuddy.link` 对含 `MicroMessenger` 的 UA 一律返回 403**（平台自己的"请在浏览器中打开"页），站点侧无开关。被拦时二选一：换到不拦微信的宿主（实测 `*.pages.dev` / `*.github.io` / `*.netlify.app` 通过，需自有账号、换完必须复验），或留在原宿主但改文案并说明真实表现。
   - 引擎已内建微信内置浏览器适配：meta 全套（`format-detection` 防数字变电话、X5 系列、og 分享卡片）、`confirm/alert/prompt/window.open` 一律禁用改应用内弹层、`navigator.share` 降级为"点右上角 ···"引导、iOS 输入框 16px 防强制放大、`overscroll-behavior` 防下拉露白。

## 使用示例

- 把这份知识库做成一个闯关 H5
- 重点做成微信里也能用：二维码要能被微信扫出来，链接在微信里要能打开
- 生成永久公开的在线链接和二维码海报，手机电脑都要能正常玩
- 给成品加上 AI 语音朗读，英语内容要能中英文切换音色
- 给我出 10 道关于[主题]的闯关题，带解析
- 诊断我的学习情况，推荐下一步该学什么

## 附带技能：knowledge-to-agent（v2.2）

专家包自带 `skills/knowledge-to-agent`，含完整管线：

```
kb_parse.py      解析知识文件 → levels_<场景>.json（统一 Schema）
kb_enrich.py     补全 alt(换个说法) / 逐选项反馈 / 缺失解析
gen_questions.py 题目不足 3 道的关卡用题型转换补齐
merge_kb.py      合并所有场景 → levels_all.json
build_index.py   拼装 KB + app_core.js + tts.js + app_ui.js + template.html → 单文件 index.html
make_qr_poster.py 云端链接 → 二维码海报（微信规范 + 双重反解校验 + 独立二维码大图）
wechat_check.py  微信生态体检：链接可打开性 / meta / 受限 API / 二维码
```

⚠️ **执行顺序不可乱**：`merge_kb → gen_questions → build_index`。顺序错了会静默丢题。

技能内含「AI 语音朗读」「交付链路（强制门禁）」「跨端适配」「**微信生态交付**」四大章节，覆盖：语种分轨与音色选择、标点不朗读、长句换气、移动端解锁与看门狗、双端自适应断点表、在线链接发布与公开性体检、二维码微信规范与压缩链路校验、微信内置浏览器适配清单、宿主被拦时的两条出路与交付话术、离线单文件、PDF 与演示视频。

## 注意事项

- **不编造事实**是第一铁律：宁可少出题，不可错出题。
- **数字口径**：宣称的关卡/题目数必须 = 真实可玩数，不要用"地图规划数×3"估算。
- **交付别停在本地**：默认动作是「发布在线链接 → `curl` 体检 200 → 据内容烧二维码海报 → 双端自检 → 微信体检 → 顺带离线单文件」。
- **双端别只测 PC**：扫码打开的人几乎都在手机上，必须 390×844 + 1440×900 各跑一遍。
- **"浏览器打得开"≠"微信打得开"**：默认宿主对 `MicroMessenger` UA 返回 403。微信场景必须先跑 `wechat_check.py`，没验过不许写"微信可打开"。
- **"能解出"≠"微信能扫"**：静区 3 模块、彩色前景、非整数缩放都能骗过 cv2 却骗不过微信。按合规参数出图并过模拟压缩校验。
- **微信里禁用 `confirm()/alert()/prompt()/window.open()`**：iOS 微信静默返回 false，不报错也不提示（"清空进度"会点了没反应），一律改应用内弹层。
- 浏览器直连大模型会暴露 API Key，仅适合自用/演示；对外部署建议加服务端代理。
- 对外交付的成品需脱敏，源码注释与界面文案中不得残留内部文档名或项目代称；改了源文件要联动重生成 PDF、视频、PPT 截图与交付包。
